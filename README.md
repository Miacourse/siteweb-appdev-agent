# Siteweb/AppDev Agent

Agent spécialisé dans la création **professionnelle** de sites web et d'applications.

## Stack

- **Frontend** : Next.js + React + TypeScript + Tailwind CSS
- **Données / authentification** : Supabase (Postgres + Auth + Storage)
- **Déploiement** : Vercel (auto-déploiement depuis ce dépôt — un `push` = une mise en prod)

## Ce qu'il fait

Sites vitrines, landing pages, applications web (SaaS, dashboards, e-commerce), portfolios — du brief initial jusqu'à la mise en production, avec une qualité de niveau agence : responsive, accessible, performant, SEO.

Voir [`SKILL.md`](SKILL.md) — rôle, workflow en 5 étapes (comprendre → concevoir → développer → tester → déployer), normes professionnelles, outils, livrables.
